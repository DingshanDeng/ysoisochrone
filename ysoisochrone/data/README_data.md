# README for Data Matrix

Here are the collection of prepared matrix for out of box usage. These data matrix serve as a archive of the existing stellar evolutionay tracks. 

If you use any of the matrix we provided here, please still refer to the original publication. Please also refer to the original publication for updated tracks.

If you find the tracks provided here cannot meet your need, please also download the tracks from their original website and also modify the data matrix using the function to build your own matrix (see tutorial for more details).

**Current version archived here:**

2025/11/18; Dingshan Deng and Luigi Zallio.

**PARSEC v2.0 (updated 2026 for ysoisochrone v1.2.0):**

`PARSECv2p0_AgeMassGrid_YSO_builtin_matrix.mat` is now built from the PARSEC v2.0 **2025**
release (`PARSECv2.0_ROT_2025`, non-rotating, Z=0.014; Nguyen et al. 2025). The previous
grid, built from the 2022 archive that the PARSEC team has since discontinued, is retained
as `PARSECv2p0_2022_AgeMassGrid_YSO_builtin_matrix.mat` for reproducibility and is reachable
via `set_tracks('parsec_v2p0_2022')`. Benchmarking shows the two grids give consistent
inferred masses and ages, well within typical uncertainties; test on your own sample if this
matters. For questions about the tracks, contact the PARSEC team
(https://stev.oapd.inaf.it/PARSEC/).
